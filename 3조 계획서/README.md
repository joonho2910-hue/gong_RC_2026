- 이준호: 주피터 터미널 내 tmux 백그라운드 구동 방법 알아보기 및 계획서 작성
- 이서현: YOLOv8n(경량 모델)으로 웹캠 실시간 객체 탐지를 구현하고, 사람 감지 시 TTS 음성 경고를 붙였고, 라이다 센서 퓨전·장애물 회피 조향 로직까지 코드로 작성했습니다 (단, 라이다/조향 관련은 Jetson 실기에서만 테스트 가능). + 윈도우 환경에서 테스트
- 이현준: 오토카와 핸드폰을 연결하는 방법을 찾아보았습니다. 추천하는 방법으로는 오토카와 핸드폰의 wifi를 같게 하고 jupyter를 활용하여 ip주소 연결 후 jupyter에 코드를 쳐서 조종하는 것이었습니다. 이건 그냥 조이스틱으로 조종하는 방법이고 webview로 하는 것은 찾고 있습니다
- 김주형: 전방 좌측(315°~360°) 및 전방 우측(0°~45°) 경계 영역 내에 700mm(70cm) 이내의 일반 장애물이 진입하는지 실시간 스캔 기능을 테스트함.
