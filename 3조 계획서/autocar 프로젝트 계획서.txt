# 자율주행 파트 계획서

**담당 파트**: 자율주행 (객체 인식 기반 추적 주행)

---

## 1. 개요

본 파트는 오토카에 탑재된 카메라와 라이다 센서를 이용하여, **사람을 인식하고 자율적으로 따라 주행**하는 기능을 구현한다. 

기존에 고려되었던 트랙 라인 트레이싱 방식은 현장 테스트 결과 강한 역광 환경에서 색상 기반 인식의 정확도를 보장하기 어렵다고 판단하여 채택하지 않았다. 대신 **YOLO 객체 인식을 이용한 사람 추적 주행**을 핵심 기능으로 선정하였다. 이는 라인이나 트랙 같은 고정된 환경 조건에 의존하지 않고, 실외 다양한 장소에서 재현 가능하다는 장점이 있다.

## 2. 목표

- 카메라로 촬영한 영상에서 사람을 실시간으로 인식한다.
- 인식된 사람과의 상대적 위치(좌우 방향)와 거리를 판단하여, 차량이 해당 인물을 일정 거리를 유지하며 따라가도록 조향 및 속도를 제어한다.
- 라이다를 이용해 진행 방향의 장애물과의 거리를 상시 감지하여, 충돌 위험 시 우선적으로 정지하는 안전 기능을 병행한다.

## 3. 시스템 구성

| 구성 요소 | 역할 |
| :--- | :--- |
| **정면 카메라 (CSI)** | 사람 인식을 위한 영상 입력 |
| **YOLO (YOLOv3-tiny)** | TensorRT 최적화를 통한 실시간 사람 탐지 및 위치/크기 산출 |
| **라이다 (LiDAR)** | 360도 거리 측정, 충돌 위험 시 최우선 정지 신호 제공 |
| **Jetson Nano** | 센서 데이터 통합 판단 및 조향/속도 명령 변환 |
| **오토카 (`Pilot.AutoCar`)** | 실제 물리적 조향 및 전후진 제어 실행 |

> **역할 분리 원칙**: 카메라(YOLO)는 "무엇을, 어느 방향에서" 인식하는 역할을, 라이다는 "얼마나 가까운지"를 판단하는 안전 담당 역할을 맡아 서로 보완한다. 두 판단이 충돌할 경우, 안전을 위해 라이다의 정지 판단이 항상 우선한다.

## 4. 동작 알고리즘

### 4-1. 사람 인식 및 추적 로직
1. **탐지**: 매 프레임마다 YOLO로 화면 내 모든 객체를 탐지하고, `person` 클래스만 필터링.
2. **대상 선정**: 여러 명일 경우, 화면상 박스 면적이 가장 큰(=가장 가까운) 사람을 대상 선정.
3. **조향 제어**: 대상의 중심 좌표와 화면 중앙을 비교하여, 좌우 위치에 따라 조향값 계산 (PID 제어).
4. **속도 제어**: 박스 크기(면적 비율)를 거리 근사치로 사용하여 전진/저속/정지 상태 제어.
5. **이탈 시**: 대상이 화면에서 사라지면 즉시 안전하게 정지.

### 4-2. 라이다 기반 안전 정지
- 사람 추적 로직과 독립적으로 동작하며, 전방 근접 장애물 감지 시 항상 최우선으로 정지 명령 적용.

## 5. 기술적 특징

- **경량 모델 채택**: On-device(Jetson Nano) 환경을 고려하여 YOLOv3-tiny 적용.
- **TensorRT 최적화**: 추론 속도를 기존 6 FPS에서 30 FPS 수준으로 약 5배 향상.
- **오프라인 동작**: 인터넷 연결 없이 시스템 내부에서 독립적으로 추론 및 제어.

## 6. 향후 진행 계획

| 단계 | 내용 |
| :--- | :--- |
| **완료** | YOLO 모델 경량화 및 TensorRT 변환, 실시간 추적 로직 구현 |
| **진행 예정** | 사람 추적 기능 실기 테스트 및 파라미터 보정 |

## 7. 기대 효과

- **환경 독립성**: 트랙이 없는 실외 다양한 장소에서 시연 가능.
- **직관성**: 사람을 따라간다는 시각적 기능으로 시연 전달력 극대화.
- **안전성**: 라이다 이중 안전장치를 통한 인식 오류 및 장애물 충돌 방지 구조 확보.
